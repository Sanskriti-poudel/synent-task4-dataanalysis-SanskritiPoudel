# 🚢 Titanic Data Analysis Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive data analysis dashboard built using Microsoft Power BI on the Titanic Dataset.
The goal is to explore passenger data and uncover key factors that influenced survival during the Titanic disaster.

---

## 🎯 Objective

* Analyze passenger demographics and survival patterns
* Identify trends based on age, gender, and class
* Build an interactive dashboard for easy data exploration

---

## 📂 Dataset Description

The dataset contains information about Titanic passengers, including:

* Passenger ID
* Name
* Age
* Gender
* Ticket Class (Pclass)
* Fare
* Survival Status

---

## 🛠 Tools & Technologies

* **Power BI** – Data visualization and dashboard creation
* **Microsoft Excel / CSV** – Data source
* **Data Cleaning Techniques** – Handling missing values, formatting

---

## 🔄 Data Cleaning & Preparation

Before visualization, the dataset was preprocessed:

* Removed or handled missing values (Age, Cabin, Embarked)
* Converted data types where necessary
* Renamed columns for better readability
* Removed irrelevant columns

---

## 📊 Dashboard Features

### 🔹 Key Metrics

* Total Passengers
* Total Survived
* Average Age
* Min & Max Age

---

### 🔹 Visualizations

* **Bar Chart:** Survival count by age
* **Donut Chart:** Gender distribution
* **Line Chart:** Fare vs Age
* **Pie Chart:** Survival by passenger class
* **Combined Charts:** Age vs Gender vs Survival

---

## 🔍 Key Insights

* Female passengers had a higher survival rate than males
* First-class passengers were more likely to survive
* Most passengers were between ages 20–40
* Higher fare passengers had better survival chances

---

## ⚡ Interactivity

* Filters and slicers allow dynamic exploration
* Selecting one chart updates all other visuals
* Enables deeper insight into passenger segments

---

## 🚀 How to Use

1. Open the `.pbix` file in Power BI Desktop
2. Interact with filters and visuals
3. Explore patterns and insights

---

## 📌 Conclusion

This dashboard transforms raw Titanic data into meaningful insights using visual storytelling.
It demonstrates how data visualization can help understand real-world patterns and support data-driven decisions.
